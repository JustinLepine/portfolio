# Portfolio

Personal portfolio site built with React, TypeScript, and Three.js. Deployed on Vercel.

## Stack

- **React 19** + **TypeScript**
- **Three.js** — 3D animated blob scene
- **React Router** — client-side routing
- **Sass** — styling
- **Vite** — build tooling

## Sections

- **Hero** — typewriter animation with rotating taglines
- **About** — bio, current role, stack, and quick facts
- **Story** — interactive timeline with personal background

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview production build locally |
| `npm run lint` | Run ESLint |

## Deployment

Deployed via Vercel. Output directory is `dist` (configured in `vercel.json`).

Live: https://portfolio-blush-pi-48.vercel.app/
